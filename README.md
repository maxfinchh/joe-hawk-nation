# Hawk Nation

A mobile community for sports picks, conversations, and premium content. Built with React Native and Expo for iOS and Android.

## Features

- Email sign-up and login
- Free and premium picks
- Comments, replies, likes, and media sharing
- Profile management and subscription purchases

## Getting started

```bash
npm install
npm start
```

Run a native development build with `npm run ios` or `npm run android`. Native builds require Xcode or Android Studio, respectively.

## Built with

React Native · Expo · Firebase · RevenueCat

Firebase handles authentication, data, and media storage. RevenueCat handles premium subscriptions; native builds are needed to use in-app purchases.
